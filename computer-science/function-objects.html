Function pointers and function objects

A function pointer stores the address of a function and calls it later; a function object (functor) is an instance of a class with operator(), which can carry state; both let an algorithm take behaviour as a parameter.

Definition

  • Function pointer: double (*f)(double) = &sqrt; f(2.0);. A type alias makes it readable: using Fun = double(*)(double);.
  • Function object: an object of a class that defines operator(), so obj(x) is a call. Unlike a function pointer it can keep state (parameters, counters) and can be inlined by the compiler.
  • std::function<R(Args...)> (header <functional>) wraps any callable with that signature: function pointer, functor, lambda.

Example

Intuition

Passing a function is passing a decision: the algorithm knows how to iterate, the caller knows what to do at each step.

Pitfall

A plain function pointer cannot capture context; to pass "multiply by " with a run-time one needs a functor or a capturing lambda.
