Fixing violations

  • Setup: shorten the critical path (logic restructuring, faster gates, retiming, pipelining) or lengthen the period.
  • Hold: add delay (buffers) on the short path; lowering the frequency does not help.

Intuition

Setup is a race the data must win against the next edge; hold is a race the data must not win against the current one.

Pitfall

A violated constraint leaves the flip-flop possibly metastable: its output can hover between 0 and 1 for an unbounded time. Asynchronous inputs, which can violate any constraint, need a two-flip-flop synchroniser.
