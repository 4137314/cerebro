Iterators and for-each in Java

Every Collection<E> gives an Iterator<E> with hasNext(), next() and remove(); any Iterable can be scanned with the for-each loop, which is compiled into an iterator; the iterator is the only safe way to remove elements while scanning.

Intuition

An iterator is a cursor that knows the structure it walks; for-each hides it when you only need to read.

Pitfall

Calling words.remove(w) inside a for-each over words changes the collection behind the iterator's back: the next next() throws ConcurrentModificationException.
