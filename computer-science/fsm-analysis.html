Analysis of synchronous sequential circuits

In a synchronous circuit the state held by the flip-flops and the inputs of clock cycle determine the next state and the outputs ; to analyse a circuit, read from the logic driving each flip-flop input and from the logic driving the outputs, tabulate them over all state–input combinations and draw the state diagram.

Method

Model: flip-flops hold the present state , a vector of bits, constant for the whole clock cycle ; combinational logic computes the next state and the outputs; at the active edge . With edge-triggered flip-flops present and next state are separate signals: the equations are explicit, no stability problem.

  1. For each flip-flop input, follow the logic backwards to primary inputs and flip-flop outputs: the expressions are the next-state function .
  2. Do the same for each primary output: the output function .
  3. State table: one row per (present state, input), rows for flip-flops and inputs; columns: next state, outputs.
  4. State diagram: a circle per state (at most ), an arrow per row from present to next state labelled input/output. Each state has outgoing arrows (rows with the same next state and output can share one arrow with a don't-care label).
  5. Read the behaviour off the diagram and say in words what the circuit does.

Every returns to 00, with unless it was already in 00. So: the machine waits in 00 with ; when becomes 1 it leaves 00 (and stays out while : 01→11→10→10…); when returns to 0 it raises for that cycle and goes back to 00. It signals the end of a pulse of ones — a Mealy falling-edge detector.

Intuition

Analysis is mechanical — a computer could do it: the creative part is only the last step, naming what the states remember.

Pitfall

The output written on an arrow belongs to the present state and input (the cycle before the transition), not to the state the arrow points to. Unreachable codes (here none) still need a row: after a glitch the machine may land there.
