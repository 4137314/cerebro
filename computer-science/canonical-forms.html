Terms:

  • literal: a variable or its complement; the number of literals measures the cost (each is a gate input, so roughly transistors);
  • minterm: a product in which every variable appears once (); it is 1 on exactly one row;
  • maxterm: a sum in which every variable appears once (); it is 0 on exactly one row;

First canonical form (canonical SOP): minterms of the rows with . A variable appears plain if it is 1 in that row, complemented if 0. Second canonical form (canonical POS): maxterms of the rows with . A variable appears plain if it is 0 in that row, complemented if 1.

Derivation

Expanding on and then on in both cofactors:

After all variables every coefficient is a constant : the products multiplied by 0 vanish, those multiplied by 1 stay. That is the first canonical form, read directly off the truth table. The dual expansion keeps the sums whose constant is 0 (a sum containing a 1 is 1 and disappears from the product). Uniqueness: the terms are fixed by the table, so equal functions have equal canonical forms — unlike ordinary expressions, where and look different and are the same function.

Intuition

A minterm is a detector for one row; OR-ing the detectors of the ones rebuilds the table. A maxterm is a detector (active low) for one zero; AND-ing them forces the output to 0 exactly there.
