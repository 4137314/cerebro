Public, protected and private inheritance in C++

C++ derives with public, protected or private; the mode caps the visibility of the inherited members in the derived class, and only public inheritance makes the derived class a subtype usable through base pointers and references.

Definition

In class D : mode B, a member of B with visibility is seen in D with visibility , where private protected public; private members of B are never accessible in D.

member of B public inheritance protected inheritance private inheritance
public public protected private
protected protected protected private
private not accessible not accessible not accessible

Only with public inheritance is "D is-a B" visible outside: a D* converts to B*, a D& to B&, and D objects can be used wherever B is expected. Private inheritance means "implemented in terms of", like a private member.

Example

Slicing

Assigning a derived object to a base object (not pointer or reference) copies only the base part: Character c2 = *w; would keep no wizard. Polymorphism in C++ needs pointers or references.

Intuition

The inheritance mode is a filter on the way down; public is the only one that lets the outside world see the family relation.

Pitfall

class defaults to private inheritance, struct to public: class D : B {} silently makes D not a subtype of B.
