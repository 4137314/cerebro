7-segment decoder: don't-cares and joint minimization

Each of the seven segments is a separate 4-input function of the digit ; for hexadecimal digits segment needs 14 literals, but if only BCD digits 0–9 can occur the six unused codes are don't-cares and needs 6; across outputs a product already built for one segment can be reused by another even when it is not prime there.

Intuition

Don't-cares are free ones: every unused code is a cell the map may claim to make a rectangle bigger. Sharing gates between outputs is the same idea one level up: the cheapest term is the one already in the circuit.

Pitfall

With don't-cares the circuit's output on the unused codes is whatever the chosen cover says (here 1010 lights segment ): fine only if those codes really never occur. Joint minimization by hand is error-prone; for several outputs, tools do it (the multiple-output version of the cover problem).
