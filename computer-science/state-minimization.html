State minimization

Two states are equivalent when, for every input sequence, they produce the same output sequence; equivalent states can be merged without changing the behaviour; the minimal machine is found by partition refinement — split first by outputs, then repeatedly split any block whose states move, on some input, into different blocks — until nothing changes.

Method

  1. : group the states with the same outputs for every input (same row of outputs in the table).
  2. : two states stay together only if, for every input, their next states lie in the same block of .
  3. Stop when : each block is one state of the minimal machine.

Quick special case: two rows with identical outputs and identical next states are equivalent at once. Machines with different numbers of states can do exactly the same thing; the minimal one is unique up to renaming.

Intuition

States that no experiment can tell apart are the same state with two names.

Pitfall

With don't-cares in the table (incompletely specified machines) equivalence is no longer transitive and the problem becomes hard; also, the minimal number of states is not always the cheapest circuit — a few extra states (one-hot, or an output-decoded encoding) can shrink the logic.
