Mealy versus Moore machines

In a Moore machine the outputs depend only on the present state, so they are written inside the states, are constant for the whole clock cycle and react to an input one cycle late; in a Mealy machine they depend on state and inputs, are written on the arrows, react within the same cycle and often need fewer states — but they follow input glitches and two Mealy machines connected in a loop can close a combinational cycle.

Definition

  • Moore: . Output logic fed by the flip-flops only.
  • Mealy: . Output logic fed by flip-flops and inputs.

Every Moore machine is a Mealy machine whose outputs ignore the inputs; a Mealy machine is converted to Moore by splitting each state according to the output with which it is entered (more states, one cycle later).

Intuition

Moore answers "where am I?", Mealy answers "where am I and what is happening now?" — the second is quicker and more nervous.

Pitfall

When several machines talk to each other, a Mealy output feeding another Mealy machine's input whose output comes back closes a loop with no flip-flop in it: possible oscillation. With Moore machines (or registered Mealy outputs) every loop crosses a register. In an ASM chart a Mealy output is a conditional output box, never a state.
