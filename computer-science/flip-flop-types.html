Definition

type Q⁺ 0→0 0→1 1→0 1→1
D D 0 1 0 1
T T ⊕ Q 0 1 1 0
JK J·Q̄ + K̄·Q 0- 1- -1 -0
SR S + R̄·Q, SR=0 0- 10 01 -0

The last four columns are the excitation table: the input values (JK, SR as pairs) that produce the transition; "-" is a don't-care. JK is an SR whose forbidden combination has been given a meaning: toggle. T is a JK with . D is the cheapest and the default in synchronous design and in FPGAs.

Method

Synthesis with a flip-flop other than D (step 4 of FSM synthesis): for each state bit and each row of the state table, look up the transition and write the required inputs; then make one Karnaugh map per flip-flop input (two for JK) instead of one per next-state bit.

Intuition

The characteristic equation answers "what will it do?" (analysis); the excitation table answers "what must I tell it?" (synthesis).

Pitfall

A T flip-flop must start from a known state: toggling an unknown value gives an unknown value forever — give it a reset. In an excitation table, 1→1 for JK is with free, not .
