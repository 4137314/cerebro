Definition

  • finite set of states, reset state, inputs, outputs;
  • next-state function;
  • Moore: , outputs depend only on the state, change only after a clock edge;
  • Mealy: , outputs react to inputs in the same cycle, often with fewer states.

State encoding maps to bit vectors: binary ( flip-flops), Gray (one bit changes per transition, low power), one-hot ( flip-flops, simple and fast next-state logic, common on FPGAs).

Intuition

The state is everything the machine needs to remember about the past; the diagram is the whole behaviour on one page.

Pitfall

Mealy outputs pass combinationally from inputs to outputs: two Mealy machines connected in a loop can form a combinational cycle. Register the outputs when in doubt.
