Method

An algorithm takes a range [first, last) and, optionally, a callable:

  • non-modifying: find, find_if, count, count_if, for_each, equal, min_element;
  • modifying: copy, transform, replace_if, remove_if (moves the kept elements forward, then erase), reverse;
  • sorting and searching: sort (random access, ), stable_sort, partial_sort, binary_search=/=lower_bound on sorted ranges in ;
  • numeric: accumulate, inner_product, iota.

A comparator must be a strict weak ordering: comp(a, b) true when goes before .

Intuition

Write the loop once, correctly, in the library; say only what differs (the predicate) at the call site.

Pitfall

std::sort needs random-access iterators, so it does not work on std::list, which has its own member l.sort(). remove_if does not change the size of the container.
