Sequential circuits: memory through feedback

A combinational circuit gives the same output for the same input; a function whose output depends on the input history is sequential and needs memory, obtained by feeding an output back to an input (the boiler controller ); separating the memory into well-understood elements and updating it only at clock events gives synchronous circuits, otherwise the circuit is asynchronous and can race or oscillate.

Definition

  • Combinational: (after the transient). Same input, same output, whenever it occurs.
  • Sequential: the output depends on the sequence of past inputs; the part of the past that matters is the state, stored in memory.

Structure: a combinational network computes outputs and next state from inputs and present state; a memory holds the present state.

  • Asynchronous: the state changes as soon as the next state changes; present and next state depend on each other immediately (feedback through wires).
  • Synchronous: the state is updated only at events of a special signal, the clock; between events the next state can settle without affecting the present one.

Intuition

Memory is a loop that keeps telling itself the same thing; a clock decides when it is allowed to listen to something new.

Pitfall

A feedback equation may have no stable solution ( oscillates) or more than one ( can hold either): asynchronous loops must be designed for stability and against races. Keep loops inside known memory elements and let the rest be combinational.
