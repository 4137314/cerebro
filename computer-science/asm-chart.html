Algorithmic state machine (ASM) charts

An ASM chart draws a state machine as a flowchart: a rectangle per state with its Moore outputs, diamonds testing input conditions (one true and one false exit), rounded boxes for conditional (Mealy) outputs; arrows from one state to the next may pass through several decisions, but every path must end in a state, and inputs are never assigned nor outputs tested.

Definition

  • State box (rectangle): name, optional code, outputs asserted for the whole cycle (Moore). Unlisted outputs are 0 by default.
  • Decision box (diamond): a Boolean condition on inputs (or on datapath status signals); two exits, 1 and 0. Decisions can be chained to factor complicated conditions.
  • Conditional output box (rounded rectangle) on a path: outputs asserted while in the source state and the conditions on the path hold — a Mealy output. It is not a state and takes no clock cycle.
  • One ASM block = a state box with everything hanging below it until the next state boxes: everything in a block happens in the same clock cycle; the transition happens at the edge.

Rules: never assign a value to an input (you cannot decide it); never test an output (you already know it); no loop made only of decisions (with no state box inside it the values never change, the machine would be stuck).

Example

Boiler, Moore: state OFF (): diamond ; 1 → ON, 0 → OFF. State ON (): diamond ; 1 → OFF, 0 → ON. Two decisions express the four transitions. Mealy version: in OFF, on the path a conditional box — the burner starts in the same cycle in which is seen.

Picture

Mealy boiler: the cyan conditional box turns the burner on in the cycle in which is detected.

Intuition

It reads like a program — "in this state do this, if that go there" — which is why it scales to the controllers of RTL designs.

Pitfall

Two conditional boxes for the same output on different paths are fine; a conditional box that drives a register load still takes effect only at the next edge (the register shows the new value in the next state).
