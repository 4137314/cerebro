Dynamic gate operation

  • Precharge (CLK = 0): PMOS on, foot NMOS off → .
  • Evaluate (CLK = 1): PMOS off, foot on → output discharges if the pull-down network conducts, otherwise floats high.

Inputs must be stable (or only rise) during evaluation: cascading requires domino logic (dynamic gate + static inverter) so that all inputs are low during precharge (Krambeck et al. 1982).

Charge sharing and leakage

If an internal node was discharged and connects to the output without a full path to ground: . Leakage slowly discharges the floating output: minimum clock frequency, or a weak keeper PMOS.

Pass transistors

NMOS pass gate: passes 0 well; passing 1 the output stops at (with body effect), so the next inverter may leak. Transmission gate (NMOS ∥ PMOS, complementary gates): full swing, parallel of the two. Used in multiplexers, XORs, latches.

Engineering applications

High-speed datapaths (domino adders in older CPUs), register files, memory decoders, precharged bit lines in SRAM and DRAM (same precharge/evaluate idea), transmission-gate latches.

Pitfall

Dynamic gates consume power on every clock (precharge) even if the output does not logically change; activity factor can exceed that of static logic.
