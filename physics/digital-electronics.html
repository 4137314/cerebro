Course conventions (used in every note)

symbol meaning
K'n = μn·Cox process transconductance (µA/V²)
Kn = K'n·(W/L) device transconductance
saturation I_D = (Kn/2)(V_GS − V_TN)², if V_DS ≥ V_GS − V_TN
triode I_D = Kn(V_GS − V_TN − V_DS/2)V_DS
body effect V_TN = V_TO + γ(√(V_SB + 2φF) − √(2φF))
on-resistance R_on = 1/(Kn(V_DD − V_TN)), R_eq ≈ 1.7·R_on
delays t_PHL = 0.69·1.7·R_on·C, t_f = 2.2·1.7·R_on·C

How to solve an exam exercise

  1. Guess the region of each transistor (saturated if ; triode if the output is "low").
  2. Equate the currents of devices in series; solve the quadratic; discard the root that violates the region.
  3. Verify the guessed regions a posteriori.
  4. For timing, replace each conducting path by its equivalent resistance and use / .
  5. Power: static (ratioed logic), dynamic .
