Image storage formats: BSQ, BIL, BIP

A cube of lines, columns and bands can be written band after band (BSQ), line after line with all bands of each line (BIL), or pixel after pixel with all bands of each pixel (BIP, also BIS); the choice decides which access is fast.

Definition

Offset of sample in a flat array:

format order on disk offset of sample (b, y, x)
BSQ, band sequential band, line, pixel b·N·M + y·M + x
BIL, interleaved by line line, band, pixel y·B·M + b·M + x
BIP/BIS, by pixel line, pixel, band (y·M + x)·B + b

Example

Intuition

BSQ is a stack of single-band pictures; BIP is a list of spectra; BIL is in between and matches how a pushbroom acquires a line.

Pitfall

Reading a pixel's spectrum from a large BSQ file touches distant locations on disk; reading one band from BIP touches every pixel. Pick the layout for the dominant operation or convert once.
