Look-up tables and visualization

Screens show 256 gray levels per channel, while sensors deliver up to DNs; a look-up table is an associative memory applied pixel by pixel, which converts (and enhances) the data for display without changing the stored values.

Example

Sentinel-2 delivers 16-bit data (–); a natural scene occupies maybe –. Mapping the full 16-bit range to 256 levels would squeeze the scene into the first 16 gray levels: almost black. A LUT on uses the whole display range.

Intuition

A LUT is the display's lens: it decides which part of the data's range gets the screen's limited shades.

Pitfall

Visual enhancement must not be confused with data processing: classify and measure on the DNs (or reflectances), not on the stretched 8-bit display values.
