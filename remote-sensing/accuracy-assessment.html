Accuracy assessment and the confusion matrix

A classified map is evaluated on independent test samples: the confusion matrix counts test pixels of reference class labelled as class ; overall accuracy is the diagonal fraction, producer's and user's accuracies measure omission and commission per class, and Cohen's kappa discounts agreement expected by chance.

Intuition

The diagonal is what the map got right; off-diagonal cells say which classes it confuses and in which direction.

Pitfall

Overall accuracy hides rare classes: a map that never finds the 2% of burnt area can still have 98% OA. Look at per-class accuracies, and sample test pixels independently from training areas.
