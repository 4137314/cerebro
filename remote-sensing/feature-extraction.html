Feature extraction

Feature extraction computes, for each pixel (pixel-based) or each segmented region (region-based), a vector of parameters useful to discriminate the classes — original bands, spectral indices such as NDVI, texture measures, region shape — normalised to a common range before classification.

Method

Input: multispectral and/or multiband, multipolarization images, pre-processed. Features:

  • unaltered bands;
  • indices from band ratios and differences (NDVI, water and snow indices) that enhance a property and reduce illumination effects;
  • texture (variance, entropy, co-occurrence measures).

Approaches:

  • pixel-based: one feature vector per pixel; the output is a set of feature images, one per feature. Suitable when classes are internally homogeneous at the image resolution.
  • region-based: segment first, then compute region descriptors (mean DN, area, perimeter, compactness, texture). Suitable for very high resolution images where objects span many heterogeneous pixels.

Normalisation: each feature mapped to by or standardised to zero mean and unit variance, so that no feature dominates distances only because of its units. Selection: keep the subset that best separates the classes (separability measures, wrappers), fighting the curse of dimensionality.

Example

Intuition

Features are the questions the classifier is allowed to ask about a pixel; good questions make the answer easy.

Pitfall

More features are not always better: with few training samples, adding weak features lowers accuracy (Hughes phenomenon).
