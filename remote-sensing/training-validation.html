Training, validation and test samples

Labelled samples are split into a training set (fit parameters), a validation set (choose hyperparameters and features, stop training) and a test set (estimate accuracy once, at the end); k-fold cross-validation reuses small sets, and in remote sensing the split must be spatially independent — whole fields or blocks, not random pixels — or accuracy is overestimated.

Method

  • Hold-out: e.g. 60/20/20. The test set is never used to make decisions.
  • k-fold cross-validation: split the training data into folds; train on , validate on the remaining one, rotate, average. Used to choose of an SVM, the network size of an MLP, the number of features.
  • Stratification: keep class proportions in every fold, or sample rare classes deliberately and weight the accuracy.
  • Spatial independence: neighbouring pixels are nearly identical (spatial autocorrelation). Assign whole polygons (fields, buildings) or spatial blocks to one set only.
  • Overfitting signal: training accuracy keeps rising while validation accuracy falls.

Example

Intuition

Do not mark your own homework: the data used to make choices cannot also judge them.

Pitfall

Random pixel splits from the same fields routinely report 99% accuracy for models that fail on a new region; reporting how the samples were split is as important as the accuracy itself.
