#+TITLE: The order of an element and cyclic groups
#+DATE: [2026-08-09 Sun]
#+FILETAGS: :growing:algebra:group_theory:
#+MSC: 20A05, 20K01
#+HASH: 01c385373125

The subgroup generated by a single element is the smallest interesting
one, and it is completely understood: there are exactly two cyclic groups
up to isomorphism for each possible size. That classification is the
first place where a family of groups is described once and for all, and
it turns questions about an element into arithmetic in \(\Z\).

#+DEPENDS: def-generated-subgroup
#+NAME: def-cyclic-group
#+begin_definition
A group \(G\) is /cyclic/ if \(G = \langle a \rangle\) for some
\(a \in G\), that is if every element is a power \(a^{n}\) with
\(n \in \Z\). Such an \(a\) is a /generator/.
#+end_definition

#+DEPENDS: def-cyclic-group
#+NAME: def-order-of-an-element
#+begin_definition
The /order/ of \(a \in G\) is the least \(n \ge 1\) with \(a^{n} = e\),
if such an \(n\) exists, and \(\infty\) otherwise. It is written
\(\ord(a)\).
#+end_definition

#+DEPENDS: def-order-of-an-element
#+NAME: prop-order-and-powers
#+begin_proposition
Let \(a\) have finite order \(n\). Then \(a^{m} = e\) if and only if
\(n \mid m\), the elements \(e, a, \dots, a^{n-1}\) are distinct, and
\(\langle a \rangle = \set{e, a, \dots, a^{n-1}}\) has exactly \(n\)
elements. If \(a\) has infinite order, the powers \(a^{m}\),
\(m \in \Z\), are pairwise distinct.
#+end_proposition

#+begin_proof
Write \(m = qn + r\) with \(0 \le r < n\). Then
\(a^{m} = (a^{n})^{q} a^{r} = a^{r}\), so \(a^{m} = e\) exactly when
\(a^{r} = e\), which by minimality of \(n\) forces \(r = 0\); this
proves the divisibility criterion and shows every power lies in
\(\set{e, \dots, a^{n-1}}\). If \(a^{i} = a^{j}\) with
\(0 \le i \le j < n\) then \(a^{j-i} = e\) with \(0 \le j - i < n\), so
\(j = i\). For infinite order, \(a^{i} = a^{j}\) with \(i < j\) would
give \(a^{j-i} = e\) with \(j - i \ge 1\), contradicting that no such
power exists.
#+end_proof

#+DEPENDS: def-cyclic-group, prop-order-and-powers, prop-subgroup-criterion
#+NAME: thm-subgroups-of-a-cyclic-group
#+begin_theorem
Every subgroup of a cyclic group is cyclic.
#+end_theorem

#+begin_proof
Let \(G = \langle a \rangle\) and \(H \le G\). If \(H = \set{e}\) it is
cyclic. Otherwise \(H\) contains some \(a^{m}\) with \(m \ne 0\), hence
(taking inverses) some positive power; let \(d\) be the least positive
integer with \(a^{d} \in H\). For any \(a^{m} \in H\) write
\(m = qd + r\) with \(0 \le r < d\); then
\(a^{r} = a^{m}(a^{d})^{-q} \in H\), so \(r = 0\) by minimality. Hence
\(H = \langle a^{d} \rangle\).
#+end_proof

#+DEPENDS: def-cyclic-group, thm-first-isomorphism-groups, def-order-of-an-element
#+NAME: thm-classification-of-cyclic-groups
#+begin_theorem
A cyclic group is isomorphic to \(\Z\) if its generator has infinite
order, and to \(\Z/n\Z\) if the generator has order \(n\).
#+end_theorem

#+begin_proof
Let \(G = \langle a \rangle\) and let \(\varphi \colon \Z \to G\) be
\(\varphi(m) = a^{m}\); it is a homomorphism from \((\Z,+)\) because
\(a^{m+m'} = a^{m}a^{m'}\), and it is surjective by definition of
\(\langle a \rangle\). Its kernel is a subgroup of \(\Z\), hence
\(n\Z\) for a unique \(n \ge 0\) by the previous theorem applied to the
cyclic group \(\Z\). By the first isomorphism theorem
\(G \iso \Z/n\Z\). If \(a\) has infinite order the kernel is trivial,
\(n = 0\) and \(G \iso \Z\); otherwise \(n\) is the least positive
integer with \(a^{n} = e\), which is \(\ord(a)\).
#+end_proof

#+begin_remark
So the order of an element is two things at once -- the size of the
subgroup it generates and the modulus of the arithmetic in it -- and
this is why Lagrange's theorem, a statement about sizes, immediately
yields \(a^{\abs{G}} = e\), a statement about exponents.
#+end_remark
