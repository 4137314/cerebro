#+TITLE: Tag taxonomy

The controlled vocabulary is data, not documentation: it lives in
=org-tag-alist= in .emacs.d/lisp/cerebro-org.el, and any tag used in a
note that isn't declared there gets flagged by =bin/cerebro-lint=
(tier 1, no Org-roam needed). This file is what each one *means* --
extend the vocabulary in cerebro-org.el first, then explain it here.

* Maturity (mutually exclusive)

Borrowed from the "evergreen notes" idea: make how well-formed an idea
still is visible, instead of only implying it.

- =seed= :: a fragment, a question, something copied from a lecture
  almost verbatim. Not yet understood well enough to explain in your
  own words.
- =growing= :: reworked at least once, connected to other notes, but
  still has rough edges or open questions attached.
- =evergreen= :: written in your own words, understood well enough to
  teach, stable under revision. This is the tag =cerebro-query.el='s
  "stale hubs" query cares about: an evergreen note nobody has touched
  in a long time is fine; a =growing= one that's also a hub is a
  signal to go back and finish it.

* Difficulty (mutually exclusive)

=easy=, =medium=, =hard= -- relative to your own current level, not to
some absolute scale. Re-tag as you improve; a note doesn't need to keep
the difficulty rating you gave it as a first-year student.

* Epistemic status (freestanding)

These matter structurally, not just descriptively: =bin/notes-lint.el=
(tier 1) treats a =theorem=/=lemma=/=proposition=/=corollary= special
block with no adjacent =proof= block as an error *unless* its heading
carries one of these tags.

- =conjecture= :: believed true, not proved (by you, or at all).
- =folklore= :: "well known," proof omitted because it's standard/long
  /ubiquitous, not because it doesn't exist.
- =open_problem= :: actually unresolved (in the field, not just by you).

* Area (a two-level hierarchy, freestanding, extend freely)

The coarse "what shelf" dimension. It is data in
=.emacs.d/lisp/cerebro-taxonomy.el= (=cerebro-area-taxonomy=), spliced
into =org-tag-alist= as Org /group tags/: a *supertag* stands for all
of its *subtags*, so filtering the agenda or a query by =analysis= also
matches a note tagged only =functional_analysis=.

Supertags (each with its own subtags -- see the file for the full
list): =analysis=, =algebra=, =geometry=, =topology=, =number_theory=,
=foundations= (incl. =logic=, =category_theory=), =combinatorics=,
=probability=, =dynamics=, =numerics=, =mathematical_physics=.

Tag with the *most specific* subtag you can (=riemannian_geometry=, not
just =geometry=); the supertag still finds it. Add an area by editing
=cerebro-area-taxonomy=; both the linter's vocabulary and the agenda
grouping update from it automatically.

* Classification: the =#+MSC:= keyword (not a tag)

The fine "what leaf" dimension, and the one journals want. Recorded as
a per-file keyword, not a tag (MSC codes carry punctuation tags can't):

: #+MSC: 47A75, 46C05, 35Q41

The codes are MSC2020 (data in =.emacs.d/lisp/cerebro-msc.el=). The
first is the primary classification. =bin/cerebro-lint= rejects a code
that is not valid MSC2020 and nudges (advisory) an =evergreen= note that
has none. On a =paper=/=preprint= export the codes become
=\subjclass[2020]{...}= automatically; =make query Q=by-msc= and
=make stats= read them back. The area tags above are for quick
browsing; MSC is for precise filing and publication -- keep both.

* Functional tags (freestanding, drive actual behavior)

Not descriptive metadata -- these two change what a tool does.

- =crypt= :: this heading's body is encrypted at rest
  (=cerebro-crypt.el=, built on Org's own =org-crypt=). Symmetric
  (passphrase) by default.
- =drill= :: this heading is a spaced-repetition flashcard
  (=cerebro-drill.el=, =emacs-org-drill=): heading = prompt, body =
  answer. The =f= (flashcard) Org-roam capture template
  (=cerebro-roam.el=) creates the right structure for you.
- =daily= :: an org-roam-dailies journal note (=C-c n d=), living in
  =notes/daily/=. Set automatically by the dailies capture template
  (=cerebro-roam.el=); you rarely type it by hand.
