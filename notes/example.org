#+TITLE: A first cerebro note: uniqueness of limits
#+LATEX_CLASS: cerebro
#+OPTIONS: toc:nil

This file exists to exercise the parametric export pipeline end to end:

: make export FILE=notes/example.org PROFILE=full
: make export FILE=notes/example.org PROFILE=statements-only

Compare the two PDFs: the proof disappears in the second without a
single word of the source changing. See .emacs.d/lisp/cerebro-latex.el
for how, and latex/cerebro.cls for the shared theorem environments.

Convention: never set =#+LATEX_CLASS_OPTIONS= or =#+EXCLUDE_TAGS= in a
note file -- profile selection controls the equivalent of both at
export time, and a file-local setting would silently win over it. Write
special block names lowercase (=#+begin_theorem=, not =#+begin_Theorem=).

#+begin_definition
A sequence $(a_n)_{n \in \mathbb{N}}$ of real numbers /converges/ to
$L \in \mathbb{R}$ if for every $\varepsilon > 0$ there exists
$N \in \mathbb{N}$ such that $|a_n - L| < \varepsilon$ for all $n \geq N$.
#+end_definition

#+begin_theorem
If $(a_n)$ converges to both $L_1$ and $L_2$, then $L_1 = L_2$.
#+end_theorem

#+begin_proof
Suppose $L_1 \neq L_2$. Let $\varepsilon = |L_1 - L_2| / 2 > 0$. By
convergence to $L_1$ there is $N_1$ with $|a_n - L_1| < \varepsilon$ for
all $n \geq N_1$; similarly there is $N_2$ for $L_2$. Then for
$n \geq \max(N_1, N_2)$,
\[|L_1 - L_2| \leq |L_1 - a_n| + |a_n - L_2| < 2\varepsilon = |L_1 - L_2|,\]
a contradiction. Hence $L_1 = L_2$.

Note for note authors: keep LaTeX display equations like the one above
on a single line starting with =\[=, not =|=. A line whose first
character is =|= is Org table syntax, full stop -- it will silently
eat a multi-line =\[ ... \]= display equation instead of passing it
through to LaTeX (this bit the very first draft of this file).
#+end_proof
