#+TITLE: cerebro issues
#+STARTUP: overview

Personal, non-proprietary issue tracker AND the project's committed
roadmap: plain Org headings, no external service, no database. This file
is versioned in git on purpose -- it is the shared, reproducible task
state, so a fresh clone (and a fresh Claude Code session -- see
../CLAUDE.md) sees what is planned and why. Personal time tracking is
separate and local (Taskwarrior/Timewarrior); to time-track work on an
issue, =org-clock-in= on its heading (cerebro-time.el mirrors it into
=timew=).

Everything here is scriptable (see ../CLAUDE.md and the =cerebro= CLI):
=cerebro issue list|show|close|start|reopen|report=, =cerebro issue new
"title" [tags...]=. Inside Emacs: =C-c a i=, =C-c i=, =C-c c i=.
Priorities are Org's own =[#A]/[#B]/[#C]=.
